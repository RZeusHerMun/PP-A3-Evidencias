## Cómo se lee

- **D7, D23…** = sesión número 7, 23… con el practicante (lunes, miércoles y jueves, 9:30–14:00).
- **R** = día solo de Rafa en la oficina, sin el practicante.
- **S1…S10** = semanas del programa.
- **RS01, RS02…** = reunión de seguimiento número 1, 2… (jueves 11:00–12:00, con Dirección, ejecutivas y practicante).
- **Track** = proyecto de prácticas profesionales. 
	- A: análisis de mercado. 
	- B: flujo operativo de la oficina.
- **Semáforo de dominio:** 🔴 Expuesto (lo oyó) → 🟡 Reconoce → 🟢 Produce (lo hace solo con checklist) → 🔵 Explica (se lo enseña a otro y detecta el error ajeno).
- "Sin registro" quiere decir que la bitácora no lo anota. No quiere decir que no haya pasado.
- Los clientes aparecen como *caso 1, caso 2…*. Las afianzadoras sí van con su nombre.

## Cómo se actualiza

Cada jueves se agrega la nota de la reunión de seguimiento en `07_Reuniones/`. Agrego una nota de semana cada viernes y actualizo el resumen ejecutivo en cada corte. Cada corte queda marcado como una *release* del repositorio. Si en **Watch → Custom** marca **Releases**, GitHub le avisa por correo.
